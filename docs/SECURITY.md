# 安全检查记录

日期：2026-10-15。范围：本项目代码、当前锁定 npm 依赖、生成测试资料及应用配置。不是对所有上游源码逐行审计，也不保证未来没有新漏洞。

## 依赖与供应链

- 依赖固定版本并提交 package-lock.json，使用 npm 官方源，先 `--ignore-scripts` 安装。
- Electron 44.7.2 从官方 GitHub Release 下载，SHA-256 对照 npm Electron 包内 checksums.json：`10a89447ef64ac5cb9f782af48ffd83734a40ae91681259d1048ca3c9e6c5da4`。
- 最初 electron-builder 26.15.3 经 global-agent 3 引入有 DoS 公告的 sprintf-js。尝试审计建议的旧版会引入更严重且已知的工具链漏洞，因此最终保留最新版并覆盖为 global-agent 4.1.3，其依赖不包含该日志链；实际打包已验证通过。
- 当次 `npm audit` 全量报告：0 已知漏洞；另做仅生产依赖审计。原始报告保存在本机 `test-output/`，不随仓库上传；可自行运行 npm audit 复核。审计结果是查询时的已知公告，不等同于无漏洞证明。
- 未复制 GPL/AGPL 整套阅读器源码；实际复用的 Apache/MIT 组件保留许可声明。仅使用离线资源，无 CDN、遥测或在线更新模块。

## 应用权限边界

- Electron 渲染器 sandbox=true、contextIsolation=true、nodeIntegration=false、webSecurity=true。预加载仅暴露白名单方法，不暴露 require、process、shell、通用 IPC 或任意文件读取。
- IPC 同时校验发送者窗口和主页面 URL；任务串行，限制单次请求大小。
- 导入仅由本机文件选择器，或真实 File 对象的拖入授权触发；拖入令牌一次性、5 分钟过期。不存在接受任意原始路径的渲染器导入接口。
- 文档只能按资料库内稳定 id 打开；路径穿越、内部索引目录、Windows 设备名称、符号链接及目录联接被拒绝。原生打开限制扩展名，不直接执行 exe、脚本、快捷方式或 HTML。
- CSP 限制脚本为本地资源，禁止 object、表单提交、远程连接；同时在 session 层阻断外部网络。弹窗、导航、webview、浏览器权限默认拒绝。
- PDF.js 禁用 eval 优化；不启用 PDF JavaScript 脚本管理器或外部链接执行。文件名和批注插入 HTML 前转义。

## 文件完整性与 Office

- 批注保存使用同目录临时文件和 SHA-256 冲突检查，成功后原子替换。外部修改冲突会拒绝写回，不自动覆盖。
- 未保存批注显示状态，保存失败可重试；有未保存数据时退出提示保留或放弃。第一版不提供崩溃恢复。
- 文件重名不覆盖，导入预检完整批次，跨盘复制逐文件校验。删除调用 Windows 回收站，不自行递归永久删除用户资料。
- PowerPoint 通过固定脚本与参数文件调用，不拼接 shell 代码；隐藏窗口、禁用宏，完成后恢复原自动化安全设置，只关闭本次打开的演示文稿。
- 若用户已打开 PowerPoint，不退出其应用实例；只修改测试临时文件或用户明确打开并批注的课件副本，再替换原件。每次 COM 调用设 120 秒超时；Office 插件、受保护视图或阻塞对话框仍可能导致操作失败。

## 尚需真实资料检验

课程目录整体在资源管理器中改名会失去原索引位置，应从 app 内改名。第三方修改文件的极短竞争窗口、断电、磁盘故障、网络盘、同步盘、大规模资料库及恶意文件模糊测试不在本次覆盖范围。写回重建 PDF 会影响数字签名；重要签名文档建议只读。安装包未购买代码签名证书。
