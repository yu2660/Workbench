## 已修复问题

1. Office COM `ExportAsFixedFormat` 在本机的可选参数封送不兼容，改用 PowerPoint 的 PDF SaveAs 路径，实际转换通过。
2. 阅读器页码更新后返回列表可能显示旧快照，修复本地状态更新及导航时重读持久化进度；隐藏阅读器不再错误更新页码。
3. PDF.js 6 已将文档销毁放在 loadingTask；改为正确 API，正常关闭与冲突关闭均验证。
4. 外部修改冲突时标签只能保留，增加明确放弃当前待保存批注并关闭的流程，并验证取消时保留。
5. 确认框 Promise 状态处理调整为显式完成，避免跨确认框的关闭事件误影响新的操作。
6. 拖入导入改为真实 File 对象产生的一次性令牌，渲染器不能通过公开接口直接给任意路径授权。
7. PPTX 自描述批注与课程索引增加结构校验，避免不受信任元数据进入模板。
8. 最新打包工具的旧代理/日志链存在公告；最终覆盖已修复的代理组件，保留较新的其他工具链，全量审计归零且打包通过。

## 尚未覆盖与限制

- NSIS 安装包已构建；未执行安装/卸载向导，以免修改用户的安装目录、开始菜单及桌面。打包后的独立程序已实际运行。
- 安装包未签名，Windows 可能显示未知发布者。未做 SmartScreen 声誉测试。
- 中文与常规 PPTX 已测试；复杂公式、旋转文字、组合图形、特殊字体及各种教师课件仍需真实资料验收。选中的文字映射为幻灯片标记形状，不修改文字字体属性。
- 旧版 `.ppt` 的批注不支持，需先另存为 `.pptx`。扫描 PDF 无 OCR，不能选字高亮。
- 不承诺维护 PDF 数字签名、处理加密或受保护文档、编辑其他软件的批注。已有注释保留，但第三方便签弹窗没有完整集成。
- 未做大规模性能压测、恶意文档模糊测试、断电/崩溃恢复、同步盘/网络盘测试。资料库的索引 JSON 没有崩溃自动恢复功能，重要资料应备份。
