# Workbench 0.1 系列设计

## 产品范围

仅本机 Windows 离线使用。无账号、云同步、网络请求、OCR、作业截止日期或任务提醒。课程使用名称和封面颜色区分，固定课程资料、作业、其他资料三个栏目；栏目内支持多级文件夹。

首次选择专用资料库。文件导入执行移动，而非建立引用或保留原副本。跨盘移动先复制并逐文件 SHA-256 校验，再移除原位置；失败时尽量回滚，遇到无法回滚的磁盘错误保留幸存文件。相同名称不覆盖。PowerPoint 生成的预览属于可重建缓存，不是第二份用户管理的资料。

## 页面与交互

左侧固定导航：品牌、课程书架、最近阅读、课程列表、资料库设置。顶部显示位置和文件名搜索，可限制当前课程。主区域随导航切换。

1. **课程书架**：温和的鼠尾草绿与浅色背景、简洁课程卡片、封面颜色、资料数量、最近阅读。没有虚构课程或假数据；截图中的内容全部来自隔离的测试资料库。
2. **课程页**：课程标题与设置，固定三栏目标签、文件夹面包屑、文件列表。文件夹优先，支持名称、添加时间、修改时间、最近打开的正倒序排列。行内显示当前页/总页、修改日期、大小和管理菜单。
3. **阅读空间**：顶部多标签与工具栏；正文在左、批注列表在右、缩略图预览位于最右侧。PDF 连续滚动，PPT 单页翻页并默认按窗口整页适配。支持页码跳转、75%–150% 缩放、选中文字高亮/下划线、中文便签、批注说明编辑、删除、40 步会话内撤销。Ctrl K 搜索，Ctrl Z 撤销批注。

PPT 点击「全屏放映」或按 F5 后进入真正的窗口全屏，课件保持比例适配，隐藏其他面板。单击下一页、右键上一页，支持方向键、PageUp/PageDown、空格及 Home/End；Esc 或退出按钮返回普通阅读，保留页码和原缩放。普通阅读提供默认关闭的「点击翻页」开关；拖选文字、便签和输入框操作不触发翻页。窗口尺寸变化时重新适配。

进度如 20/100 表示当前页，不推断全部读过。每份文件保留独立页码。启动进入书架，点击文件恢复位置；标签只在当前会话中保留。

## 数据与磁盘布局

```text
用户选择的资料库/
  .workbench/library.json   # 课程、稳定文件 id、阅读页码、时间戳
  高等数学/
    课程资料/              # 可包含任意子文件夹
    作业/
    其他资料/
```

应用设置位于 Electron userData/settings.json；预览缓存位于 userData/preview-cache。文件系统监视器对实际目录的变化触发防抖扫描。库内重命名/移动通过稳定 id 保留进度，外部重命名通过文件系统标识尽量关联。外部直接删除整个课程目录会显示警告；课程目录应在 app 内改名。删除送入 Windows 回收站。仅移除课程时可保留目录；创建同名课程可以重新加入含三个栏目的原目录，已移除课程的旧阅读记录不承诺恢复。

## 阅读与写回

PDF.js 负责画布、文本选择层和缩略图。PDF 的高亮、下划线、便签通过 pdf-lib 写成标准 PDF 注释，保留其他工具已有的注释。Workbench 注释附带自描述元数据，因此文件再次导入后仍能读取和编辑自己的批注。

PPT/PPTX 借助已安装的 Microsoft PowerPoint 生成带文字层的 PDF 缓存；不执行宏，不提供动画或编辑课件正文。PPTX 高亮、下划线从选择范围映射到原幻灯片坐标，作为半透明矩形/线条写回；便签使用原生 PowerPoint 评论。标记的自描述数据写入受管形状标签，可在重新打开后恢复。它们是课件中的可编辑图形标记，不修改原文字的字体高亮属性。文字已转曲或属于图片时无法选字。

保存先生成同目录临时文件，再检查原文件 SHA-256，确认没有外部修改后原子替换。写回失败保持原文件、保留当前会话待保存批注，并阻止无提示退出。旧 .ppt 可阅读，批注须先另存为 .pptx。

## 已知边界

- PowerPoint 复杂字体、公式、组合对象及旋转文字的选区映射需使用真实课件进一步验收。
- PDF 写回会重建文件结构，不适用于需要保持数字签名有效的文件；加密、受保护或只读文件可能无法批注。
- 已存在的第三方 PDF 注释保留，外观显示取决于 PDF.js 的页面渲染支持；编辑列表只管理 Workbench 创建的批注，第三方便签弹窗尚未集成。PPT 第三方评论不进入 Workbench 列表。
- 单个阅读文件上限 512 MB；大量文件、深目录、超长路径与外部并发修改还需要压力测试。
- 未保存批注不做崩溃恢复；正常保存后批注在原文件内。
