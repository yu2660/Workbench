# 公开仓库的内容与隐私检查

本仓库只发布应用源码、锁定依赖清单、测试代码、图标、文档、开源许可和生成的演示截图。

不发布 `node_modules/`、`.cache/`、`dist/`、`test-output/`、原始 `design/` 截图、个人资料库、预览缓存、用户设置、凭据或日志。忽略规则同时覆盖常见环境变量文件、私钥和机器配置；不要使用 `git add -f` 绕过这些规则上传个人资料。

首次发布前检查了待提交文件清单及实际暂存内容，移除了 README 中的开发机路径，公开截图重新从演示资料生成并隐藏路径。提交使用 GitHub noreply 邮箱，避免暴露全局 Git 配置中的真实邮箱。图片不含 EXIF 位置等附加信息。

检查包含本机用户名/路径、邮箱、私钥块、常见访问令牌格式及敏感配置文件名。源码中的 `token` 是一次性本地拖入授权标识；标准系统路径及安全测试中的占位字符串不是账户凭据。开源许可证中上游作者的姓名、邮箱和网址属于应保留的版权声明。

此记录描述首次发布时的检查范围，不构成对后续提交的自动保证。后续提交仍需审查差异和截图。构建产物如以后通过 GitHub Releases 发布，也应重新检查内容、许可证和校验和。
