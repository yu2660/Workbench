# 更新记录

## 0.1.1 — 2026-10-22

- PDF/PPT 缩略图预览移动到阅读区最右侧。
- PPT 默认整页适配窗口，调整窗口尺寸后自动重新适配。
- 新增「全屏放映」与 F5 快捷键；单击下一页、右键上一页，Esc 退出。
- 普通阅读新增可开关的「点击翻页」，默认关闭；拖选文字仍可批注。
- 支持方向键、PageUp/PageDown、空格与 Home/End 翻页；页码输入、便签编辑和按钮键盘操作不受影响。
- 退出全屏保留当前页与阅读缩放，系统退出全屏时同步恢复界面。
- 增加 14 项阅读导航与全屏回归检查；未改变资料库结构。

## 0.1.0 — 2026-10-15

首个 Windows 安装版本：课程书架、三个固定栏目、文件和文件夹管理、PDF/PPT 阅读、阅读位置记录、基础批注写回和本机离线资料库。
